# Etapa 1 — Entendendo a integração

Nesta versão, as oportunidades estão escritas diretamente no HTML. Use isso para explicar que a página ainda não consulta dados reais.

## Abrir a etapa

```bash
npm run etapa:1
```

Acesse `http://localhost:5501`.

## Demonstração sugerida

1. Mostre os dois cartões no navegador.
2. Abra o código e altere manualmente um título.
3. Explique que, sem uma API, cada mudança exige editar o HTML.
4. Apresente o fluxo usuária → front-end → API → banco de dados.
