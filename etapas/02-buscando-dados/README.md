# Etapa 2 — Buscando dados

Esta versão faz uma requisição `GET /oportunidades` e monta os cartões com a resposta da API.

## Executar

Em um terminal:

```bash
npm run start
```

Em outro terminal:

```bash
npm run etapa:2
```

Acesse `http://localhost:5502`.

## Demonstração sugerida

1. Abra `http://localhost:3000/oportunidades` para mostrar o JSON.
2. Abra a etapa no navegador.
3. Use a aba **Network** para localizar a requisição.
4. Pare a API e atualize a tela para demonstrar o tratamento de erro.
