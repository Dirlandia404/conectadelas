# Etapa 3 — Enviando dados

Esta versão lista as oportunidades com `GET` e cadastra uma nova com `POST`.

## Executar

Em um terminal:

```bash
npm run start
```

Em outro terminal:

```bash
npm run etapa:3
```

Acesse `http://localhost:5503`.

## Demonstração sugerida

1. Preencha o formulário com a aba **Network** aberta.
2. Antes de enviar, mostre o objeto criado por `FormData`.
3. Envie e destaque o código de resposta `201`.
4. Mostre o corpo da requisição e a resposta em JSON.
5. Demonstre um erro enviando um link inválido ou uma descrição curta.
